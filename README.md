# Sistema Bancario

Projeto desenvolvido em **Java** com o objetivo de praticar lógica de programação, estruturas de dados básicas e organização de código.

## Sobre o projeto

O Sistema Bancario é uma aplicação de console que permite realizar operações bancárias básicas, como criação de contas, consulta de saldos, depósitos e saques.

O projeto foi desenvolvido como parte da minha jornada de aprendizado em Java, colocando em prática os conceitos estudados no curso de Java Básico.

## Funcionalidades

- **Criar conta:** cadastra um novo titular e atribui um número à conta.
- **Consultar saldo:** permite verificar o saldo de uma conta.
- **Realizar depósito:** adiciona um valor ao saldo da conta.
- **Realizar saque:** permite retirar um valor do saldo disponível.
- **Consultar dados:** exibe as informações de uma conta.
- **Listar contas:** apresenta todas as contas cadastradas.

## Como executar

1. Clone este repositório.
2. Abra o projeto em uma IDE compatível com Java, como o IntelliJ IDEA.
3. Localize a classe `Main`.
4. Execute o método `main()`.
